Сервер (Cloudflare Worker)

Сохранения игроков (с историей версий), таблица лидеров, аукцион, страница администратора.
Настройки Worker (Settings → Variables and Secrets):
BOT_TOKEN — токен бота из @BotFather (тип Secret)
ADMIN_KEY — пароль для страницы /admin (тип Secret)
GAME_URL — адрес игры (тип Text), например https://username.github.io/repo/ — для кнопки «Играть» в чате бота
Привязка базы (Settings → Bindings → D1 database): имя переменной DB
